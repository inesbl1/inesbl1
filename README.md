## 🏆 Highlight — Competition Project

<div align="center">

### 🌍 Algerian Engineering Competition 2026 — **Digital Heroes Team**

> **Seismic Risk Analysis System** for GAM Assurances (Générale Assurance Méditerranéenne)

</div>

A full **GIS-based insurance risk platform** covering all 48 Algerian wilayas, built for the Algerian Engineering Competition 2026 with team **Digital Heroes** (Zebiri Rania, Bouali Ines, Bouti Nouha).

**Key Features:**
- 🗺️ **SIG Cartography** — Interactive seismic risk map colored by RPA zones (0, I, IIa, IIb, III)
- 📊 **Portfolio Dashboard** — Real-time cumul analysis by wilaya and risk category (Residential / Commercial / Industrial)
- 🤖 **AI Underwriting Assistant** — XGBoost hybrid system (RPA compliance + AI risk scoring) with Accept/Reject/Conditional recommendations
- 💥 **PML Simulator** — Probable Maximum Loss calculation: `Capital × Vulnerability Factor × Intensity Factor`
- 👤 **Client Risk Score** (0–100) — Location + building type + behavioral + contract value
- 📋 **ACAPS Regulatory Reporting** — Auto-generated PDF compliance reports in 10 seconds
- ⚡ **Real-Time Seismic Alerts** — CRAAG API integration
- 🎯 **Portfolio Balance Index** (0–100) — Single metric for global portfolio health
